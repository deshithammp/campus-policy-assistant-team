# DS205.3 submission checklist

1. Add all three members' names and student IDs and complete their personal reflection in the editable technical report. Include actual decisions and outcomes that each member can defend.
2. Publish the group's repository on public GitHub and use meaningful commits authored by the members doing the work. In a public checkout fetch the examination PDFs from the source manifest when needed. Include the repository URL in the final hand-in.
3. Upload CampusPolicyDemo.mp4 to the group's YouTube channel with Unlisted visibility if permitted, or use the video as a rehearsal and record your own walkthrough. Check audio and playback and include the watch link in the submission.
4. Use nLearn for the deadline and submission instructions. The brief sets a 50 MB technical package limit, a 3,000-word report maximum, and a five-minute video maximum.
